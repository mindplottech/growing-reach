# 3D を描いて画像で確かめる

テストは計算しか確かめない。3D の見た目は描かないとわからない（今日見つかった例：背が台帳の身長より 7.5% 低い、腕の構えが逆向き、近い画面で育ちが見えない、歩き回る子が中央値の子ではなかった）。

## 手順

1. `bash scripts/render-check.sh` を実行する（初回は three.js r170 を GitHub から .cache/three に取る。Chrome が要る）。
2. `.cache/shots/` の画像を **Read で開いて自分の目で見る**：
   - `figure-ages.png`：1歳3か月・2歳6か月・4歳のあーちゃん。月齢で背が伸び、頭の比率が小さくなるか。顔が崩れていないか。
   - `figure-reach.png`：手を伸ばす姿。手が顔を隠していないか。
   - `figure-look.png`：見ている人の方へ振り向くか。ほぼ後ろ向きの子は前を見ているか。
   - `app-15.png`・`app-60.png`：部屋全体。身長の帯の数字が台帳の中央値と合うか（15か月で登れる高さ 40cm・立って届く 86cm）。
   - `help-switch-15.png`・`help-switch-30.png`：踏み台が月齢で低くなるか（35cm → 15cm）。
3. 見た目を直したら、もう一度描いて前後を比べる。比べた画像は KO に送る。
4. 図形だけを見たいときは `scripts/figure-preview.html` に URL の引数を付ける：`?months=15,30,48`、`&arms=2.98`、`&turns=1.4,-1,2.2&look=1`、`&close=1`。

## 決まり

- 見た目は表示だけ。計算（sim/）と台帳の値は変えない。図形の全高は台帳の身長に合わせる。
- 「描けなかった」「見ていない」ことは、そのまま KO に言う。見ていない画像について「確かめた」と書かない。
