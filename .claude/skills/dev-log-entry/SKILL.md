# dev-log に1節書く

docs/dev-log.md は、ハッカソン期間中に何を作り、誰が何を決めたかの記録。審査で「イベント中に作られたもの」と「人と AI の分担」を示す証拠になる。

## 形

```
## YYYY-MM-DD 見出し（何をしたか、短く）

- 取り消した決定：（あれば）何を取り消し、何にしたか。理由と、誰の判断か。
- 原因：（不具合の直しなら）何が起きていて、なぜか。
- Claude Code に任せたこと：作ったもの・変えたファイル・数値。確かめた方法（テスト何件、描いて見た画像、headless Chrome など）。確かめられなかったことも書く。
- 私（KO）の判断：KO が決めたこと・指摘したこと。Claude Code が決めて KO の確認待ちのものは「Claude Code が決めた（KO の確認待ち）」と分けて書く。
```

## 決まり

- KO が決めていないことを「KO の判断」と書かない。
- 数値は実際に出した値を書く（例：「15か月で踏み台35cm」「テスト265件通過」）。
- 書いたら `npm test` → コミット → `git push`（CLAUDE.md の手順。コミット前の確認は hooks が走らせる）。
