# ブラウザでの動作テスト（Claude in Chrome に貼るプロンプト）

以下をそのまま Claude in Chrome に貼る。手元で `git pull` → `npm start` をしてから使う。

---

あなたは、子どもの環境調整を見せるウェブアプリ「あーちゃんが やる！」のテスト担当です。コードは変えず、画面を操作して確かめ、最後に報告をまとめてください。

## 開くページ
- http://127.0.0.1:8080/ （開けなければ https://mindplottech.github.io/growing-reach/ ）
- 新しいタブで開き、ウィンドウの幅は 1280px 以上にする。開いたら5秒待つ。

## 0. 最初の画面
- コンソールにエラー（赤字）が出ていないか、`error` で絞って読む。画面下に赤い「3D表示でエラー」の文が出ていないか。
- 見出しが「あーちゃんが やる！」、左に道具の列がなく、3D の左上に案内文が出ていないこと。
- 3D の家で子ども（あーちゃん）が動いていること。スクリーンショットを撮る。

## 1. 月齢ごとの点検（いちばん大事）
右の欄の月齢スライダーを、次の月齢に順に合わせる：0歳9か月、1歳0か月、1歳3か月、1歳6か月、1歳9か月、2歳0か月、2歳3か月、2歳6か月、2歳9か月、3歳0か月、3歳6か月、4歳0か月、4歳6か月、5歳0か月。部屋は「すべて」を選ぶ。

それぞれの月齢で、右の欄を記録する：
- 「この時期の遊び・生活」に出ている項目
- 「🪜 大人がひと工夫すると、自分でできる」のタイル（名前とバッジ：踏み台○cm・○cmより下に・手前○cmに）
- 「🤗 大人と一緒に」のタイル
- 「✓ もう自分でできる」のチップ
- 「これから」と「⚠️」の行
- 3D のあーちゃんの姿：1歳3か月まではおむつ姿で、動くときははいはい（四つ這い）、止まると家具につかまって立つ。1歳4か月からは T シャツで歩く。

そのうえで、**発達支援と子育ての目線で不自然なところ**を探して挙げる。たとえば：
- 2歳を過ぎても手洗いが「抱っこで」のまま（2歳からは踏み台で立つ練習をしてほしい）
- 2歳半より前に、手洗い以外で踏み台が出る
- 台所（調理台）を一人でやらせるように見える
- トイレの項目が4歳より前に出る
- ほかに「この月齢でこれは早すぎる・遅すぎる」「この助けは現場では勧めない」と感じるもの

## 2. 部屋のボタン
3歳0か月で、右の欄の部屋のボタン（リビング・洗面所・トイレ・玄関・台所・すべて）を順に押す。それぞれで確かめる：
- カメラがその部屋に寄るか。見えにくい部屋（壁で隠れる、遠すぎる）はないか。
- あーちゃんがその部屋から動き出すか（押して3秒以内に、その部屋の中にいるか）。
- タイルがその部屋のものだけになるか。
- 玄関：ドア側（手前）が土間、その奥に木の段差になっているか（段差がドアにくっついて見えないか）。
各部屋でスクリーンショットを撮る。

## 3. 助けの場面
- 2歳6か月・リビングで「スイッチ（🪜 踏み台15cm）」のタイルを押す。カメラが寄り、踏み台が置かれ、あーちゃんが乗って手を伸ばすか。3D の上に一行（「2歳6か月：踏み台 15cm があると → 電気をつける」）と「助けなし／助けあり／閉じる」が出るか。
- 「助けなし」「助けあり」を切り替える。
- 場面を開いたまま、スライダーを2歳11か月へ（踏み台10cm になるか）、3歳4か月へ（場面が閉じて家全体に戻るか）。
- 1歳3か月で「スイッチ（🤗 抱っこで）」を押す。一行が「大人が抱っこして → 電気をつける」になり、踏み台が出ないか。
- 「閉じる」で家全体に戻るか。

## 4. そのほか
- 3D の下の「子どもに近づく」を押す → あーちゃんに寄って追いかけるか。もう一度押すと戻るか。
- 再生・一時停止のボタン。
- ヘッダーの「使い方」「根拠を見る」を開いて閉じる。「根拠を見る」に「作者 KO（発達支援の実務）の判断」の項目（踏み台を使い始める月齢、年ごろの遊びと生活、つかまり立ちのころ）があるか。
- 動きがカクつく、ボタンが反応しない、文字が重なる・切れる、などがないか。

## 報告の形
1. まとめ（3行以内）
2. 不具合の表：どこで／何をしたら／何が起きたか／期待／スクリーンショットの番号
3. 月齢ごとの点検の表：月齢／ひと工夫／大人と一緒に／もう自分で／不自然な点
4. 不自然な点の一覧（重要な順）と、そう感じた理由

操作が2〜3回続けて失敗したら、無理に続けずそこまでを報告してください。
