# 提出用の概要

## English (summary, 100–200 words)

**あーちゃんが やる! ("Let me do it!") — Growing Reach**

Toddlers say "I'll do it myself!" long before their bodies can: the picture book on the high shelf, their own cup in the cupboard. The child is not at fault; the home is built for adult bodies, and the environment draws out the behavior. Changing the home helps, but which change is hard to put into words. Development is invisible; the environment is not. So this tool makes it visible.

For children aged 9–60 months it computes height, reach and climbable height from Japanese public surveys and sorts things to do at home into "can do alone", "with this help", "with an adult" and "not yet". The numbers come from surveys; how to use them comes from practice: a one-year-old could reach the light switch from a stool, but their footing is unsteady, so the app shows "held by an adult" instead. Adults are environment too. Age is a slider: an order, not a date. In 3D, あーちゃん stands on the stool and reaches.

Every number is read from a ledger cited to table and page. Claude Code built it; hooks block any commit failing the tests. No AI runs inside the app, and no input leaves the browser.

## 日本語

**あーちゃんが やる！ — Growing Reach**

子どもは、体が追いつく前から「自分でやる！」と言います。高いところの絵本を自分で取りたい。食器棚の自分のコップを自分で出したい。やりたいのにできない、は、子どもが悪いのではなく、家が大人の体に合わせて作られているからです。環境が、その子の行動を引き出している。だったらその力を、子どもの「できる」を増やす方に使えばいい。環境を変えれば解決できることが多いのですが、どこをどう変えればよいかは言葉では伝わりにくい。発達は見えませんが、環境は見えます。だから、見えるようにしました。

0歳9か月〜5歳の子の身長・立って届く高さ・登れる高さ・肘の高さを、公的調査と研究の値から計算し、家の中のやりたいことを「自分でできる／この助けがあればできる／大人と一緒に／まだ」に分けます。体の数字は公的調査から、それをどう使うかは現場から。数字の上では1歳でも踏み台に乗ればスイッチに届きますが、1歳の足元はふらふらなので、踏み台は出さず「抱っこで」とします。環境は物だけでなく、大人も環境です。月齢はスライダーで、「何歳でできる」ではなく順序の見通しとして見せます。行を押すと、3D の家であーちゃんが踏み台に乗って手を伸ばし、スライダーを動かすと、背が伸びて踏み台が低くなります。

数字はすべて、表とページまで書いた出典と、格上げしない4つの区分つきの台帳から読みます。作ったのは Claude Code で、テストと台帳の検証に通らないコミットは hooks が止めます。作品の中では AI も API も使わず、ブラウザを開くだけで誰でも無料で使えます。入力はブラウザの外に出ません。
