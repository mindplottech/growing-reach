- Claude Code に任せたこと：`sim/helpScene.js`（計算側・乱数なし）を足した。やりたいこと1つについて、子どもが立つ位置（物の縁から20cm）、置く助け（踏み台＝その子に必要な高さ／段を下げる／縁に寄せる）、助けなし・ありそれぞれの足の高さと手の高さ・届くかどうかを数値で返す。届く・登れるの判定は adjustments.js の結果をそのまま使い、新しい式はない。3D（`render/view3d.js`）は右の欄の行を押すと、その場所へカメラを寄せ、踏み台を描き（段を下げる・寄せるときは物を動かし）、子どもを踏み台の上に立たせて手を伸ばす姿勢にする。3D の上に一行（「1歳3か月：踏み台 10cm があると → 自分で席に着く／踏み台の上なら、登れる」）と「助けなし／助けあり／閉じる」を置いた。月齢スライダーを動かすと、見ている場面がその月齢で計算し直され、踏み台が低くなり、自分でできる月齢になると踏み台が消えて「助けはいらない」になる。最初の画面は、選んだ部屋で最初に助けが要るやりたいことを開いた状態にした。部屋を切り替えても同じ。再生・場面を見るボタン・表の行を押すと場面は閉じ、100人の試行の再生に戻る（裏で自動再生が続いていても閉じない）。
- 表示の決まり：3D の一行は体の事実（届く・登れる・肘の高さ）だけを書き、やりたいことの名前は右の欄と同じ語。踏み台の寸法（幅40・奥行き30、立つ距離20cm）は `sim/params.js` の仮値（表示だけ）。踏み台の高さは1つずつの行にその子に必要な高さを書き、複数あるときは「1つにするなら、いちばん高い○cm」を添えた（以前は全部に最大値を書いていた）。
- テスト：`test/helpScene.test.js` 5件（家具の中に立たない、踏み台の上で届き・床からは届かない、段を下げる・寄せるは物だけ動く、できる・まだは小道具なし、同じ入力で同じ結果）。全 258 件通過。
- 私（KO）の判断：「大人の助けを置いて、子どもがそれを使うところを見せる」方向と、1（置いて見せる）→4（一行）→3（スライダーで踏み台が低くなって消える）の順（2026-11-05）。
